Architecture & Add-on Engine

Decoupled administration plane on top of headless Spring Authorization Server.

Spring Boot 4.1

The ed-idp Admin Console runs as an isolated add-on module powered by modern Bootstrap 5.3, Thymeleaf, and reactive HTMX. When disabled in production via edidp.ui.enabled=false, the core engine operates as an ultra-lean, headless OAuth 2.1 & OpenID Connect 1.0 Authorization Server.

Multi-Tenant Isolation
Thread-scoped tenant propagation using Java 25 ScopedValue without thread-local leakage.
Modular Monolith
Strict boundary enforcement with Spring Modulith 2.1 across users, oauth, claims, and tokens.
